A courier account holds the keys that read the courier's data, so it is the admin who adds and changes one. Everything a courier sends back is still yours to read on the courier pages.

Add an account

One row per account, not per courier. PostEx - RB and PostEx - AH are two accounts sharing the same courier, and Trax or M&P are added here the same way. What each one asks for is its own business — PostEx needs a token, M&P a login as well — so the boxes change with the courier picked. Whatever is typed is checked with the courier before it is kept.
